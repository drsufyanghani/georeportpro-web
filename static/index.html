Consultancy Workflow

The web version follows the same engineering workflow as the desktop PoC.

1. Import professional Excel workbook 2. Review project metadata, borehole logs and laboratory data 3. Run completeness, range and PSD consistency QC 4. Review calculation outputs and IS references 5. Review sample-wise and borehole-wise figures 6. Export a professional Word report 7. Qualified engineer validates and signs off final values

Engineering Position

Automated results support engineering review; they do not replace it.

Final values, classifications, correlations, assumptions and recommendations must be checked, validated and approved by a qualified geotechnical engineer before client issue.
